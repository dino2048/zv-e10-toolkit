# 硬件与接线

这条链路需要 RP2040 Pico、固定接线和电池/上电时序。

## 必需

- ZV-E10；
- RP2040 Pico；
- 470Ω 电阻；
- USB-C 接线；
- 相机电池。

## 引脚

A6/A7 是 USB-C 插座上的数据引脚编号：

- **A7 = D−**；
- **A6 = D+**。

## 接线

| Pico | 相机 USB-C | 说明 |
|---|---|---|
| **GP28** | D−（A7） | 直连 |
| **GP27** | **470Ω → D+（A6）** | 复位线，必须串 470Ω |
| 5V | VBUS | — |
| GND | GND | 共地 |

- 注入期间相机 USB-C 接 Pico，不接电脑；
- D− 使用 open-drain，不要 3.3V 推挽；
- GP28 和 GP27 的功能不能互换。

如果不行，翻转 USB-C 方向再试。

## 电池与上电

v15 复位注入：

- 相机正常开机，电池插着；
- 脚本先开载波，再发 GP27 10 µs 低脉冲复位相机，然后整组重放；
- 不需要拆电池。

回退：`--no-reset` 电池法：

- 相机 OFF、取电池、断开 VBUS；
- 脚本要求 D− 低基线；
- 看到 `CARRIER ON` 后插电池。

## 换线到电脑

- payload 检测 VBUS 低 → 高；看到长闪后把相机 USB-C 从 Pico 移到电脑；
- Pico 5V 和 Mac 5V 会在相机 VBUS 上顶在一起，Pico 可能从 Mac 掉线，不影响已经在运行的 payload。

## LED

- 一次长闪（0.4 s）：payload 活着；
- 短脉冲计数：USB 时钟/PHY → DWC3 → EP0 配置 → 等主机；
- 之后每 2 秒一次短脉冲：在等主机枚举；
- 停在第 N 个短脉冲：对应步骤没有返回。

## 停止 / 恢复正常启动

```sh
python3 pico/reset_only.py --port /dev/cu.usbmodemXXXX
```

发一次 GP27 复位、关闭载波，相机回到正常启动，不用拆电池。也可以直接断电/取电池：
payload 在 SRAM，易失。

## 边界

- 这是 BootROM 串口启动，不是运行时漏洞；需要专用接线和上电时序。
- 只写 SRAM；不写 eMMC、SD 或 OTP。
